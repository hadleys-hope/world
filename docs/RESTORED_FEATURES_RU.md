# Восстановление планет и вождения

Причина пропажи: модульный рефакторинг был выполнен по архиву до добавления
планет и вождения. Более поздний отдельный hadleys_hope.py не попал в ту сборку.
Этот архив объединяет latest-репозиторий с отсутствовавшими функциями.

## Обновление

Распаковать содержимое папки world поверх своего репозитория world.
Архив не содержит .git, .env, сохранений мира или node_modules.
Затем из соседнего infra:

```bash
docker compose up -d --build world houses
```

Перезагрузить вкладку браузера. На 3D-карте под временем появятся кнопки
SYSTEM / HEPHAESTUS / RUSSET / ACHERON / NIX. Кнопка Drive vehicle находится
в инспекторе после нажатия на машину. Подробные клавиши перечислены в README_RU.md.
Старый MQTT-патч отдельно применять не нужно — он уже включён.

Команды запуска, Dockerfile и compose-контракт сохранены: серверу по-прежнему
нужна пересборка образа, JS-сборка и Node на production не требуются.
Старые сохранения мигрируют без сброса колонии. Планета увеличена до радиуса
4000; прежние стандартные размеры океана заменяются на 1080 × 1380.
Аттракторы, остальные страницы и локальная поставка Three.js сохранены.

Предлагаемый коммит:

```text
feat(world): restore planetary system and manual vehicle driving
```
