# NPC: статус реализации

## Сделано

- Процедурная модель человека; экипировка инженера, электрика и учёного.
- Idle/walk, плавный поворот, привязка к рельефу.
- 300 постоянных профилей: ID, дом, профессия, рабочее здание, расписание.
- Цикл `HOME → WALK_TO_WORK → AT_WORK → WALK_HOME`; смены 08:00–08:25 → 16:00–16:25.
- Пауза, сохранение состояния и маршрута, восстановление в пути, миграция старых сохранений.
- Базовая реакция на шторм и блокировку сектора; причина ожидания в карточке.
- Список жителей, карточка назначения, приближение и слежение камерой; профили доступны внутри зданий.
- Остановка в заданное время и кнопка «Продолжить · 1 мин/с».

## Осталось

1. Полностью подготовить один сектор: тротуары, переход, реальные входы двух рабочих зданий.
2. Заменить предварительные маршруты графом с поиском пути: исключить проход через здания, добавить ожидание с причиной при недоступном пути и перестроение после разблокировки.
3. Привязать постановку ног к реальным поверхностям тротуаров и входов; проверить модели и камеру в браузере.
4. Проверить укрытия при шторме на настоящих маршрутах и возврат к расписанию.
5. Показать полный сценарий сдачи: выбор NPC → работа → дом → шторм → сохранение/загрузка.
6. Замерить влияние 0/100/300 NPC: время кадра, FPS, draw calls, время серверного шага; оптимизировать по результатам.

**Ограничение:** текущие маршруты предварительные. Отсутствие прохода через здания и корректные входы пока не гарантируются. Визуальная проверка в браузере не выполнена.

## Проверка

Из каталога `world`:

```powershell
py hadleys_hope.py --port 8000 --data ./data
py -m unittest discover -s tests -p "test_*.py"
```

После перезапуска открыть `http://localhost:8000`, обновить Ctrl+F5. Выбрать «Пауза в 07:30» → «До этого времени», выбрать жителя, затем «Продолжить · 1 мин/с». Если время прошло, остановка назначается на следующие сутки. При `--data` сохранение выполняется автоматически и при штатном Ctrl+C.

Последняя проверка: **34 Python-теста прошли, 1 POSIX-тест пропущен на Windows**. Проверки JS-модулей и моделей прошли. Замеры производительности ещё не выполнены.
