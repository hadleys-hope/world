# Структура проекта после разделения

Рефакторинг основан на `world-archive.zip`. Поведение этой версии сохранено:
последующий отдельный прототип с четырьмя планетами и ручным вождением в этом
архиве отсутствовал и сюда не подмешивался.

Можно также запускать `python3 -m hadleys`.

## JavaScript и модели

3D-карта использует 42 обычных ES-модуля с явными `import`/`export`.
`main.js` задаёт порядок инициализации подсистем, `state.js` хранит их общее
изменяемое состояние. DOM/WebGL не создаются при импорте модулей:
инициализация выполняется отдельными функциями. Это позволяет избежать
циклических обращений к ещё не созданной сцене.

Связность прежней сцены ещё заметна в общем `state`: следующий архитектурный
шаг — передавать более узкие контексты в независимые подсистемы. Скрытой
склейки через `exec`, `eval` или генерацию монолитного Python-файла нет.
Файлы отформатированы; править следует именно их, генератор для запуска не нужен.

В исходнике нет STL/OBJ/GLB-моделей. Здания и машины генерируются кодом Three.js:
генератор автомобиля — `models/vehicles.js`, дома — `models/houses.js`,
материалы — `models/materials.js`, общий instancing — `models/kit.js`.
STL сюда искусственно не добавлен: он не сохраняет материалы, текстуры,
иерархию и анимации. Для будущих внешних моделей подойдёт отдельная папка
`web/static/assets/models/` с glTF/GLB; пока нужны только генераторы.

TypeScript не введён одновременно с переносом: это был бы ещё один слой
изменений и сборки. Существующий JavaScript теперь можно мигрировать по модулю.

## Дифференциальные уравнения

Векторизованная физика NumPy сохранена. `numerics.euler_step` выделяет
используемый явный шаг теплового баланса без смены шага времени или формулы.
Гидравлический решатель остаётся в своём домене. SciPy не добавлялся: здесь
не требуется смена численного метода ради разделения исходников.
Строковые enum транспорта сохраняют прежние значения в JSON и MQTT.

## Сохранённые миры

`LegacyWorldUnpickler` понимает старые пути классов `__main__.World`,
`hadleys_hope.World`, а также `Issue`, `Rover`, `UtilityNetwork`. После чтения
применяется прежняя миграция. Схема мира, `world.pkl`, `history.db` и volume
`world-data` не меняются. Новые сохранения используют пути классов пакета.
Для отката к старому монолиту нужен сохранённый до обновления `world.pkl`:
старый монолит не знает новые пути классов пакета.

Исправлено сохранение по SIGTERM после сброса колонии: сохраняется текущий
мир из `holder`, а не прежний объект, захваченный при запуске.

## Загрузка и производительность

- HTML больше не содержит сотни килобайт JS/CSS.
- `/static/` и `/vendor/` отдают gzip и ETag; неизменённые файлы возвращают 304.
- `modulepreload` загружает модули заранее, уменьшая цепочки сетевых ожиданий.
- Three.js 0.160.0 и только используемые дополнения включены в `vendor/` с лицензией.
- JSON текущего состояния остаётся `no-store`.

Разделение файлов само по себе не увеличивает FPS. В локальном браузерном
smoke-тесте, около домов с шестью активными подробными интерьерами,
`renderer.info` показал 523 вызова отрисовки и 6 184 046 треугольников.
Это один ракурс на программном WebGL, не измерение FPS на пользовательском GPU.

Следующими стоит профилировать стоимость теней, геометрию подробных домов,
перестроения LOD и raycast инспектора. Не надо одновременно менять физику,
визуальную детализацию и структуру файлов: иначе трудно определить регрессию.
Для просмотра счётчиков откройте `/?inspect` и в консоли смотрите
`HH.renderer.info`, `HH.houseDetails.size`; вкладки Performance и Memory
помогут отделить работу CPU от GPU и загрузки сети.

## Проверки

```sh
pip install -r requirements.txt
python3 -m unittest discover -s tests -v
node scripts/check-web.mjs
npm ci
npx playwright install chromium
npm run test:browser
python3 hadleys_hope.py --headless 1440
```

Фикстуры в `tests/fixtures/` получены из присланного монолита: снимки на
тиках 0/1/10/60/120, закрытие суток и месяца, два старых формата pickle.
Тесты также проверяют HTTP, кеш, защиту путей статики и обмен sensor →
controller → actuator с подменённым MQTT-клиентом, без подключения к брокеру.
Browser smoke запускает настоящий локальный HTTP-сервер и проверяет все
страницы, оба режима аттракторов и создание подробных домов.
